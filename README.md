# neosol.io

Public website for [neosol.io](https://neosol.io/), an R&D company focused
on software engineering for complex systems, from fintech and medtech to
infrastructure and beyond.

---

Everything is implemented with plain **HTML**, **CSS**, and **JavaScript**.
There is no framework, build tooling, or component layer at this stage.

This is intentional for now: the site is a single landing page with live
browser visualisations.  Although it is only a landing page, the content and
demos reflect our expertise and the kinds of projects we have delivered.
We are currently an outsourcing and consultancy company — a contractor that
do not offer public-facing services, yet.  As scope grows beyond that, a full
refactor and rearchitecture is likely; so expect significant structural change.

## Contributing

1. **Open an Issue**: If you find a bug or have a recommendation, please
   [create an issue](https://github.com/neosolabs/www/issues/new) outlining
   the details.
2. **Submit a PR**: Feel like diving into the code, patching an oversight, or
   adding something? Submit a PR.  You can also email me the patch prepared
   with either _git-format-patch(1)_ or _diff(1)_ `-ruN`.
